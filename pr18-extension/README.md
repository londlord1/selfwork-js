# Расширение «Помощник страницы» (ПР18)

Настоящее браузерное расширение (Manifest V3), которое закрывает практическую часть ПР18 и все
семь самостоятельных заданий. В отличие от демо-страниц `пр18_зад*.html`, здесь всё работает
в реальном браузере: popup, `chrome.storage.local`, контент-скрипт и обмен сообщениями.

## Что внутри

| Раздел popup | Задание ПР18 | Что делает |
|---|---|---|
| 1. Приветствие | Задание 1 | Вместо «Hello, World!» показывает «Привет, {имя}!» тостом на странице |
| 2. Фон страницы | Задание 2 | Красный, зелёный, оранжевый и **синий** (четвёртая кнопка) фон, сброс |
| 3. Размер шрифта | Задание 3 | A+ / A− по 2 px, диапазон 8–32 px, сброс. Увеличивается шрифт всех элементов страницы, картинки и сетка не масштабируются |
| 4. Счётчик кликов | Задание 4 | Считает нажатия приветствия, хранит в `chrome.storage.local` |
| 5. Тёмный режим | Задание 5 | Тёмный фон и белый текст, состояние сохраняется и применяется после перезагрузки |
| 6. Контент-скрипт | Задание 6 | Отдельный `content-script.js`: выделение заголовков, баннер, очистка |
| 7. Заметки | Задание 7 | Заметки привязаны к URL, хранятся в storage, показываются панелью на странице |

## Структура

```
pr18-extension/
├── manifest.json       # манифест MV3, права, content_scripts
├── popup.html          # интерфейс popup
├── popup.css           # стили popup
├── popup.js            # логика popup и обмен сообщениями
├── content-script.js   # скрипт, внедряемый на страницы
└── icons/              # icon16.png, icon48.png, icon128.png
```

## Установка в Google Chrome

1. Скачайте папку `pr18-extension` из репозитория:
   - либо `git clone https://github.com/londlord1/selfwork-js.git`,
   - либо на GitHub: **Code → Download ZIP**, затем распакуйте архив.
2. Откройте в браузере `chrome://extensions`.
3. Включите **«Режим разработчика»** (Developer mode) — переключатель в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку **`pr18-extension`** — ту, внутри которой лежит `manifest.json`.
   Если выбрать родительскую папку репозитория, Chrome покажет ошибку «Manifest file is missing».
6. В списке появится карточка **«Помощник страницы»**. Нажмите на иконку пазла 🧩 на панели
   браузера и закрепите расширение булавкой, чтобы его кнопка была видна.
7. Откройте любой обычный сайт (например, `https://example.com`) и нажмите иконку расширения.

> Важно: служебные страницы `chrome://…`, `edge://…`, `about:…` и Chrome Web Store расширение
> менять не может — это ограничение браузера, а не ошибка.

## Microsoft Edge

1. Откройте `edge://extensions`.
2. Включите **«Режим разработчика»** в левом нижнем углу.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `pr18-extension`.

## Яндекс.Браузер

1. Откройте `browser://extensions` (или Меню → Дополнения → Ещё дополнения).
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить расширение из папки»** и выберите папку `pr18-extension`.

## Opera

1. Откройте `opera://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `pr18-extension`.

## Firefox (временная установка)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение…»**.
3. Выберите файл **`pr18-extension/manifest.json`**.

Дополнение работает до перезапуска Firefox. Manifest V3 поддерживается в Firefox 109+;
для постоянной установки нужна подпись в AMO.

## Как проверить каждое задание

1. **Приветствие.** Введите имя, нажмите «Привет, …! 👋» — внизу страницы появится тост.
2. **Фон.** Нажмите кружки: красный, зелёный, оранжевый, синий. «Сброс» возвращает исходный фон.
3. **Шрифт.** Нажмите A+ несколько раз — текст страницы увеличивается, A− уменьшает. «Сброс» возвращает исходный размер.
4. **Счётчик.** Нажмите приветствие 3–4 раза, закройте и снова откройте popup — число сохранилось.
   «Сбросить» обнуляет счётчик.
5. **Тёмный режим.** Включите переключатель, перезагрузите страницу — режим остался. Выключите — вернулось оформление сайта.
6. **Контент-скрипт.** «Выделить заголовки» подсвечивает все `h1–h6`, «Баннер» добавляет полосу сверху,
   «Убрать эффекты» очищает всё, включая тёмный режим и фон.
7. **Заметки.** Сохраните заметку, перейдите на другую страницу — там список пуст, вернитесь — заметка на месте.
   «Показать на странице» открывает панель справа снизу, там же можно добавлять и удалять заметки.

## Права и данные

- `storage` — счётчик, тёмный режим, имя и заметки (`chrome.storage.local`).
- `activeTab` и `<all_urls>` — нужны, чтобы контент-скрипт мог менять оформление любой страницы.
- `scripting` — если вкладка была открыта до установки расширения, popup сам внедрит
  `content-script.js` в неё и повторит команду. Поэтому перезагружать страницу не обязательно.
- Расширение ничего не отправляет в сеть: все данные лежат локально в браузере.

## Обновление и удаление

- **Обновить после правок:** `chrome://extensions` → на карточке расширения нажать круглую
  стрелку «Обновить».
- **Удалить:** `chrome://extensions` → «Удалить». Заметки и настройки при этом стираются.
- После установки или обновления **перезагрузите открытые вкладки**, иначе старая страница
  не знает о новом контент-скрипте.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «Manifest file is missing or unreadable» | Выбрана папка без `manifest.json`. Выберите именно `pr18-extension/` |
| Popup открывается пустым | `chrome://extensions` → «Ошибки» на карточке; смотрите консоль popup |
| «Could not establish connection. Receiving end does not exist» | Вкладка открыта до установки/обновления — нажмите «Обновить» на карточке расширения и перезагрузите вкладку (F5) |
| Выделение заголовков не видно | На странице нет `h1–h6` (popup покажет «не найдено»), либо расширение не обновлено — нажмите «Обновить» и F5 |
| Кнопки не меняют страницу | Открыта служебная страница (`chrome://…`) или Chrome Web Store — откройте обычный сайт |
| Тёмная тема выглядит неровно | Сайт задаёт свои цвета через `!important`; это ограничение демонстрационного режима |
| Не работает на локальных файлах `file://` | В карточке расширения включите «Разрешить доступ к файлам» |
| Не видно иконку расширения | Нажмите иконку пазла 🧩 на панели и закрепите «Помощник страницы» |
