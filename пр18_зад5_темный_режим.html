ПР18 • Зад.5 • Темный режим

Создайте расширение, которое добавляет переключатель темного режима. При включении: фон → #1a1a1a, текст → белый. Состояние сохраняется в browser.storage.local.
const actions = { toggleDarkMode: function() { const isDark = document.body.dataset.dark === 'true'; if (isDark) { document.body.style.backgroundColor = ''; document.body.style.color = ''; document.body.dataset.dark = 'false'; } else { document.body.style.backgroundColor = '#1a1a1a'; document.body.style.color = '#ffffff'; document.body.dataset.dark = 'true'; } } };
💾 Состояние сохраняется в localStorage (имитация browser.storage.local)
Текущий режим: светлый
