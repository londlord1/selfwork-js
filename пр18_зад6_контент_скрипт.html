ПР18 • Зад.6 • Контент-скрипт

Напишите расширение, которое использует отдельный файл для скрипта содержимого (вместо внедрения через executeScript с code).
hello-extension/ ├── manifest.json ├── content-script.js ← отдельный файл ├── popup/ │ ├── popup.html │ ├── popup.js │ └── popup.css └── icons/ └── icon-48.png
// manifest.json { "content_scripts": [ { "matches": ["<all_urls>"], "js": ["content-script.js"] } ] } // content-script.js browser.runtime.onMessage.addListener((request, sender, sendResponse) => { if (request.command === "changeColor") { document.body.style.backgroundColor = request.color; } });

❌ executeScript (inline)

browser.tabs.executeScript(tabId, {
  code: `(${action.toString()})();`
});

✅ content_scripts (отдельный файл)

"content_scripts": [{
  "matches": ["<all_urls>"],
  "js": ["content-script.js"]
}]
