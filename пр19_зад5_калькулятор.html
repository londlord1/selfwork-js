ПР19 • Зад.5 • Режим калькулятор

Реализуйте режим "Калькулятор": бот вычисляет простые математические выражения (например, "2+2", "5*3").
function getBotResponse(userMessage) { const msg = userMessage.toLowerCase(); // Проверка на математическое выражение if (msg.includes('+') || msg.includes('-') || msg.includes('*') || msg.includes('/')) { try { const result = Function('"use strict"; return (' + msg + ')')(); return `Результат: ${result} 🧮`; } catch (e) { return 'Не могу вычислить это выражение. 🤔'; } } // ... остальные проверки }
