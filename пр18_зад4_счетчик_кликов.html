ПР18 • Зад.4 • Счетчик кликов

Создайте в popup счетчик, который показывает, сколько раз была нажата кнопка «Hello World!». Используйте browser.storage.local для сохранения между открытиями.
// Сохранение счетчика browser.storage.local.set({ clickCount: count }); // Получение счетчика browser.storage.local.get('clickCount').then(result => { const count = result.clickCount || 0; // отображаем count });
0
💾 Счетчик сохраняется в localStorage (имитация browser.storage.local)
Нажмите кнопку для увеличения счетчика.
