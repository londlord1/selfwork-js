Самостоятельные работы по JavaScript

Все самостоятельные задачи из практических работ ПР03–ПР32 — 144 страниц. Каждая задача открывается отдельно; переход между страницами — кнопками «← Пред.» и «След. →».

Как пользоваться: index.html — хаб со ссылками на все самостоятельные задачи. Страницы ПР17–ПР32 собраны скриптом make_selfwork.py. Задачи ПР26–ПР32 используют React 18 через CDN (нужен интернет), остальные работают полностью офлайн.
