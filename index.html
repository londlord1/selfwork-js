Самостоятельные работы по JavaScript

Все самостоятельные задачи из практических работ ПР03–ПР16. Каждая задача — отдельная страница. Переход между страницами — кнопками навигации.

Как пользоваться: index.html — хаб со ссылками на все самостоятельные задачи, сгруппированными по практическим работам. На каждой странице работы есть кнопки «← Пред.» и «След. →» — переход по страничкам без возврата в хаб.
