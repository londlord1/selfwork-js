ПР18 • Зад.2 • Добавить новую кнопку

Добавьте четвертую кнопку в popup, которая меняет цвет фона на синий (#2196F3).
// popup.html — добавлена новая кнопка <button id="blue-btn">Синий фон</button> // popup.js — добавлено действие const actions = { // ... существующие действия changeBlue: function() { document.body.style.backgroundColor = '#2196F3'; document.body.style.transition = 'background-color 0.5s'; } }; // Обработчик document.getElementById('blue-btn').addEventListener('click', function() { executeInTab(actions.changeBlue); });
Нажмите «Синий фон» для проверки.
