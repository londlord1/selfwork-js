ПР19 • Зад.6 • Сохранение истории в localStorage

Сохраняйте все сообщения в localStorage, чтобы при обновлении страницы история не терялась.
// Сохранение function saveHistory() { const messages = []; document.querySelectorAll('.msg').forEach(el => { messages.push({ text: el.textContent, sender: el.classList.contains('user') ? 'user' : 'bot' }); }); localStorage.setItem('chatHistory', JSON.stringify(messages)); } // Загрузка function loadHistory() { const saved = localStorage.getItem('chatHistory'); if (saved) { const messages = JSON.parse(saved); messages.forEach(m => addMessage(m.text, m.sender)); } }
💾 История сохраняется в localStorage. Обновите страницу — сообщения останутся!
