ПР18 • Зад.7 • Заметки на странице

Создайте расширение, которое позволяет добавлять заметки к любой веб-странице. Заметка сохраняется и привязывается к URL страницы. При повторном открытии страницы заметка восстанавливается.
// Сохранение заметки const url = window.location.href; const notes = JSON.parse(localStorage.getItem('notes_' + url) || '[]'); notes.push({ text: noteText, date: new Date().toISOString() }); localStorage.setItem('notes_' + url, JSON.stringify(notes)); // Загрузка заметок const savedNotes = JSON.parse(localStorage.getItem('notes_' + url) || '[]');

💾 Заметки сохраняются в localStorage с ключом, основанным на URL страницы
