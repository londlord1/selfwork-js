ПР18 • Зад.3 • Смена размера шрифта

Добавьте кнопки «Увеличить шрифт» и «Уменьшить шрифт», которые меняют размер текста на странице.
const actions = { increaseFont: function() { const currentSize = parseFloat(document.body.style.fontSize) || 16; document.body.style.fontSize = (currentSize + 2) + 'px'; }, decreaseFont: function() { const currentSize = parseFloat(document.body.style.fontSize) || 16; document.body.style.fontSize = Math.max(8, currentSize - 2) + 'px'; } };
Это демонстрационный текст. Нажмите кнопки выше, чтобы изменить его размер.
Текущий размер: 16px
Используйте кнопки для изменения размера шрифта.
