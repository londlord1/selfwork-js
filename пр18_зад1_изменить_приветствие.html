ПР18 • Зад.1 • Изменить приветствие

Измените текст всплывающего окна с "Hello, World! 🌍" на что-то другое (например, ваше имя или "Привет, студент!").
// popup.js — измененная функция showHello const actions = { showHello: function() { alert('Привет, студент! 🎓'); }, // ... остальные действия };
Нажмите кнопку для проверки измененного приветствия.
