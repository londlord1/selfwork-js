# Самостоятельные работы по JavaScript (ПР03–ПР32)

Хаб самостоятельных задач из практических работ по JavaScript. Каждая задача — отдельная
HTML-страница с рабочим интерактивным примером и раскрывающимся листингом кода.

## Как использовать

Откройте **index.html** — это хаб со ссылками на все 144 страницы, сгруппированные по практическим
работам (ПР03–ПР32). На каждой странице есть кнопки **«← Пред.»** и **«След. →»** — переход по
страницам без возврата в хаб.

## Структура

- `index.html` — хаб со ссылками на все задачи
- `пр03_зад1_…html` … `пр32_зад7_…html` — страницы задач
- `tasks_part1.py`, `tasks_part2.py`, `tasks_part3.py` — содержимое задач (ПР17–ПР32)
- `make_selfwork.py` — сборка страниц ПР17–ПР32 и хаба

## Расширение браузера (ПР18)

Помимо демо-страниц, в репозитории есть настоящее расширение **«Помощник страницы»** —
папка [`pr18-extension/`](pr18-extension/README.md). Оно закрывает практическую часть ПР18 и все
7 самостоятельных заданий: приветствие, фон страницы, размер шрифта, счётчик кликов, тёмный режим,
контент-скрипт и заметки к странице.

Установка: `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное
расширение» → выбрать папку `pr18-extension`. Подробная инструкция для Chrome, Edge,
Яндекс.Браузера, Opera и Firefox — в [`pr18-extension/README.md`](pr18-extension/README.md).

## Технологии

- **ПР03–ПР25** — чистый HTML/CSS/JS, без внешних ресурсов: страницы работают офлайн.
- **ПР26–ПР32** — React 18 через CDN (`unpkg`) с компиляцией JSX в браузере через
  `@babel/standalone@7`. Для этих страниц нужен интернет. Версии закреплены:
  `react@18.3.1`, `react-dom@18.3.1`, `@babel/standalone@7.26.4`.

## Генерация

Скрипт `make_selfwork.py` собирает страницы ПР17–ПР32 и `index.html` из данных в модулях
`tasks_part*.py`. Запуск:

```bash
python3 make_selfwork.py
```

При сборке удаляются устаревшие файлы ПР17–ПР32, которых нет в списке задач; страницы ПР03–ПР16
не затрагиваются.

## Проверка

Все 90 страниц ПР17–ПР32 прогнаны в headless Chrome: JS-ошибок нет, React-приложения
монтируются в `#root`.
