# Самостоятельные работы по JavaScript (ПР03–ПР11)

Хаб самостоятельных задач по JavaScript из практических работ. Каждая задача — отдельная
самостоятельная HTML-страница с рабочим интерактивным примером.

## Как использовать

Откройте **index.html** — это хаб со ссылками на все задачи, сгруппированными по практическим
работам (ПР03–ПР11). На каждой странице есть кнопки **«← Пред.»** и **«След. →»** — переход по
страничкам без возврата в хаб.

Все страницы автономны (inline-CSS и JS, без внешних ресурсов) — поэтому их можно просто
разместить на GitHub Pages и открывать в браузере.

## Структура

- `index.html` — хаб
- `пр03_зад1_…html` … `пр11_зад6_…html` — 38 страниц задач

## Генерация

Скрипт `make_selfwork.py` собирает страницы и index из данных внутри себя. Запуск:
`python make_selfwork.py`.
